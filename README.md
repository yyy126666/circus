# 夜间出勤 · circus_proto

1890 年代石印海报风的**警局出勤调度**原型。Godot 4.6.3 导出的 Web 构建。

**在线试玩：https://yyy126666.github.io/circus/** （约 8 秒加载，带声音，需要 https）

---

## 这个仓库里有什么

**只有导出产物，没有工程源码。**

```
index.html   Godot 的 web 壳
index.pck    游戏本体(11.6MB, 其中 4.9MB 是背景音乐)
index.wasm   引擎运行时(37MB, 换引擎版本才会变)
index.js     胶水层
.nojekyll    告诉 Pages 别拿 Jekyll 处理这些文件
```

工程源码（GDScript、PIL 烤图脚本、字体子集工具、音效合成脚本）在作者本机的另一个
目录里，没有公开仓库。想接手完整工程的话，要的是那份 `交接说明.md` —— 它记着所有
踩过的坑：美术的坐标契约、导入缓存的陷阱、导出预设不能改坏的两处、发布流程。

## 玩法

只做了第一天，分早／午／夜三班。每班桌上 4 份举报，能派出去 2 趟人。

- 点地图上的举报牌 → 开二级卷宗界面，**派人只在卷宗里做**。
- 卷宗里能让线人核实一次（判断这份举报是不是假传单），然后按工种和疲劳挑人。
- 扑空会推高左下角那只"街面态势"表；压过 30／60／90 三道刻度各触发一段固定剧情，
  90 = 当天强制结束。
- 不想派就按 **Esc** 或点卷宗外面合上。
- 收班会把这一班没去的举报算成"放过"，真举报放过一处也要加情绪。

键盘：**空格／回车**翻剧情卡，**Esc** 退出卷宗，**M** 静音，**`[` `]`** 调音量。

## 素材与许可

- **字体**：Noto Serif SC（SIL Open Font License 1.1）的子集，只含本作用到的字。
- **背景音乐**：`Kar98kurz - Agnus Dei` —— 由工程所有者提供，其声明自己持有该曲目的
  版权／许可。
- **音效**：用 numpy 合成的，不是下载来的素材。
- **美术**：底材由 gemini-3-pro-image 生成，再用 PIL 脚本合成（板子、地图、9-patch
  铜件、案卷插图都是"烤"出来的，不是手绘）。

## 重新发布

在工程目录里导出到 `web/`，再用 `tools/deploy_pages.py` 同步进这个仓库的 clone，
自己看一眼 diff 之后手动 commit + push —— 那个脚本只搬文件、不碰 git，就是为了
不让手一抖把东西发出去。

验收：`index.pck` 应该在 **11~12MB**。掉到 6~7MB 说明音频没进包，涨到 50MB+ 说明
导出预设的 `exclude_filter` 被改坏了（开发期的截图和原始底材会一起被打进去）。

导出预设里 `variant/thread_support` 必须是 `false`，否则 Pages 上跑不起来
（需要 COOP/COEP 响应头，静态托管给不了）。
